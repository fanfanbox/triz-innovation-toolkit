# TRIZ 理论学习手册 — 快速参考

## 工具选择决策树

```
问题来了
    │
    ├─ 问题是否明确？
    │   ├─ 否 → 功能分析（Ch12）/ 收敛型对话
    │   └─ 是 → 继续
    │
    ├─ 什么类型的矛盾？
    │   ├─ 技术矛盾（改善A恶化B）→ 矛盾矩阵 + 40 原理
    │   ├─ 物理矛盾（既要A又要B）→ 分离原理
    │   └─ 不确定 → ARIZ-85C
    │
    ├─ 需要预测未来？ → 8 进化趋势
    ├─ 需要降本简化？ → 裁剪
    ├─ 物质-场交互问题？ → 76 标准解
    ├─ 找实现功能的方法？ → 效应数据库
    ├─ 超级难题？ → ARIZ-85C
    └─ 需要预测/预防失效？ → AFI
```

## 物场分析四种模型

| 模型 | 状态 | 解决方案 |
|------|------|----------|
| S1─F─S2 ✅ | 有效完整 | 无需改进 |
| S1─?─S2 ❌ | 不完整 | 补充缺失的场或物质 |
| S1─F─S2 + 有害S3 | 有效但有害 | 引入新物质或场消除有害功能 |
| S1─ ─F─ ─S2 | 有效但不足 | 增强场或更换工具物质 |

## IFR 定义公式

> 系统自己完成功能，无需额外资源，无有害副作用。

## 理想化方程

$$Ideality = \frac{\Sigma Benefits}{\Sigma Costs + \Sigma Harms}$$

## 8 技术进化趋势

| # | 趋势 | 示例 |
|---|------|------|
| 1 | S曲线进化 | 灯泡：蜡烛→白炽灯→LED |
| 2 | 提高理想度 | 通信：烽火→电报→电话→手机 |
| 3 | 子系统不均衡 | 手机屏幕进化快，电池慢 |
| 4 | 向动态化进化 | 固定→可调→自适应 |
| 5 | 向微观级进化 | 手术刀→激光→纳米机器人 |
| 6 | 向超系统进化 | 手机→智能手机→物联网 |
| 7 | 向提高可控性 | 手动挡→自动挡→自动驾驶 |
| 8 | 向提高能量传递效率 | 蒸汽机→内燃机→电机 |

## ARIZ-85C 五步法

1. **问题分析与重定义** → 重新定义问题
2. **资源分析** → 识别可用资源
3. **IFR 定义** → 定义理想解
4. **物理矛盾消除** → 应用分离原理
5. **方案验证** → 评估可行性

## AFI 四步法

1. **反转任务** → "如何让系统失效？"
2. **夸大缺陷** → "最坏情况是什么？"
3. **生成缺陷** → 用 TRIZ 工具生成失效场景
4. **反转修复** → "如何防止这些失效？"
