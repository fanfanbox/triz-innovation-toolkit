## 矛盾矩阵使用方法

1. 识别改善参数（A）→ 39选1
2. 识别恶化参数（B）→ 39选1
3. 矩阵交叉点 → 1-4个推荐原理编号
4. 应用原理到具体问题

## 物场模型四种类型

1. 有效完整功能：S1→F→S2 ✅
2. 不完整功能：缺少场或物质 ❌
3. 有效但有害：S1→F→S2 + 有害→S3
4. 有效但不足：S1→F→S2（不足）
