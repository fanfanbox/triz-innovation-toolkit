# 报告质量改进方法论

## 参考报告标准

以 AITRIZ 课题报告（91页）为质量基准。

### 常见不足与改进

| 不足 | 改进 |
|------|------|
| 颗粒度不够 | 每个分析项必须有详细表格 |
| 专利分析不足 | ≥20件专利，≥4子方向详解 |
| 缺失功能分析 | 完整组件×组件相互作用矩阵 |
| 缺失物场分析 | 必须包含 Su-Field + 76 标准解 |
| 缺失 ARIZ | 复杂问题必须执行 ARIZ-85C |
| 缺失综合矩阵 | 四维度交叉映射+优先级排序 |

## 报告生成流程

```
3个并行子代理 → 合并 .md → python-docx (.docx) → docx2pdf (.pdf)
```

转换脚本: `scripts/triz_md_to_docx.py`（封面+三级目录+章节分页）

## 质量自评（10维度，每项1-10分）

流程完整度 / 详细度 / 数据支撑 / 表格规范 / 专利分析深度 / 方案可行性 / 次级问题分析 / 实施示例 / 创新性 / 可读性
