# AGENTS.md 开发迭代经验

## 版本迭代历史

AGENTS.md 经历了从 v1.0 到 v3.3.1 的迭代，每次迭代都是因为用户发现了流程遗漏。

### 关键迭代

| 版本 | 触发原因 | 新增内容 |
|------|----------|----------|
| v1.0 | 初始版本 | 路径选择网关 + 11题路由 + Triz-AI |
| v2.0 | 参考91页报告 | 三阶段流程（问题分析→方案产出→方案落地） |
| v2.1 | 用户发现遗漏 | 恢复路径选择网关 + 11题路由 + 8趋势 |
| v3.0 | 参考混动PCM报告 | 物理矛盾+物场分析+综合矩阵+ARIZ-85C |
| v3.1 | 报告不够详细 | 报告详细度要求（禁止简单列表等） |
| v3.2 | 需要质量控制 | 10维度自评 |
| v3.3 | 需要Word输出 | 双格式输出（MD+DOCX） |

### 迭代教训

1. **不要跳过基础步骤** — 路径选择网关和11题路由是基础，不能省略
2. **四维度分析必须完整** — 技术矛盾、物理矛盾、物场分析、进化趋势缺一不可
3. **报告必须详细** — 每个步骤都必须有详细表格，不能泛化
4. **专利分析必须深入** — 至少20件专利，4+个子方向
5. **必须有质量自评** — 10维度评估，给出改进建议
6. **必须双格式输出** — Markdown + Word

## 常见遗漏点

| 遗漏 | 表现 | 修复 |
|------|------|------|
| 路径选择网关 | 直接开始分析 | 首先判断放射型/收敛型 |
| 11题路由 | 跳过诊断 | 第一阶段完成后必须执行 |
| 物理矛盾分析 | 只有技术矛盾 | 分离原理是四维度之一 |
| 物场分析 | 缺失 | Su-Field + 76标准解 |
| 综合矩阵 | 各维度独立 | 必须交叉映射 |
| 报告详细度 | 简单列表 | 必须详细表格 |
| 质量自评 | 缺失 | 10维度评估 |
| Word输出 | 只有MD | 双格式 |
